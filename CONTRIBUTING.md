# Contributing

Issues and pull requests are welcome. Keep features optional, local-first and
usable alongside popular Twitch extensions.

- Discuss large features before implementation.
- Add tests for behavior and Twitch selector changes.
- Do not add telemetry or automatic message sending.
- Do not copy code without completing the provenance process in
  `docs/LICENSING.md`.
- Do not contribute AI-generated logos, icons, screenshots or other image assets.
- Use conventional commits where practical.

By contributing, you agree that your contribution is licensed under MIT.
