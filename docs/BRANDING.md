# Branding and artwork policy

PJL ViewerTools does not use AI-generated images. This applies to extension
icons, logos, screenshots, store graphics and repository artwork.

The current PJL icon is original project artwork constructed manually from
simple geometric vector paths. Its editable source is
`assets/pjl-viewertools-icon.svg`. Browser-ready PNG sizes are generated by the
deterministic local script `scripts/render-icons.mjs` and are covered by the
project's MIT license.

Future artwork must be either original human-created work or properly licensed
third-party material with provenance recorded in `NOTICE.md`. AI-generated
image assets are not accepted.
