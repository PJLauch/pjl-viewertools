# License strategy

The project is MIT to make personal use, forks, distribution and contributions
straightforward.

## Clean implementation rule

Ideas, behavior and public documentation may inform the design. Do not copy
source merely because a repository is public. Before adapting code:

1. identify the exact file and commit;
2. confirm its license and copyright owner;
3. check compatibility with MIT distribution;
4. preserve required notices and mark modifications;
5. add the provenance to `NOTICE.md` in the same pull request.

MIT code can generally be included when its notice is retained. Apache-2.0 code
requires its license and notices, change markings, and attention to patent and
trademark clauses. Code under Apache-2.0 plus Commons Clause (the current 7TV
Extension) is excluded by default because the additional restriction is not an
ordinary open-source license. Inspiration is allowed; implementation is clean.

Dependencies must be direct, actively maintained, pinned by the lockfile and
license-reviewed before release. This document is project policy, not legal
advice.
